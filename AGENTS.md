# Publicação do Feitoria Portal

Este é o repositório público de telas. O projeto completo e as instruções internas
estão no repositório privado dougfb46/feitoria-portal-interno.
Não copie histórico Git, backend, migrations, contratos, documentos internos,
cadastros, folhas, fotos de pessoas, senhas, PINs ou tokens para este repositório.
Mantenha HTML estático. Não altere o repositório separado da cozinha.
Trabalhe em branch e PR, confira a verificação de publicação antes de integrar.
Alterações no servidor exigem consultar o estado real no Supabase primeiro.
